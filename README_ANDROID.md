# 안드로이드 APK 만들기 — 따라하기

PC 버전과 **똑같은 분석 엔진**(`lotto645.py`)을 쓰는 안드로이드 앱입니다.
번호 생성 / 적중 분석 / 구간 통계 3개 화면이 모두 들어 있고,
동행복권 최신 회차 자동 업데이트도 그대로 동작합니다.

APK는 안드로이드 빌드 도구(SDK·NDK, 약 3GB)가 있어야 만들 수 있어서
**GitHub의 무료 빌드 서버**를 이용합니다. 컴퓨터에는 아무것도 설치하지 않습니다.

---

## 준비물

- GitHub 계정 (무료) — https://github.com/signup
- 이 `android` 폴더 전체

---

## 1단계 — GitHub에 저장소 만들기

1. https://github.com/new 접속
2. **Repository name**: `lotto645-android` (아무 이름이나 괜찮습니다)
3. **Private** 선택 (공개해도 되지만 비공개를 권합니다)
4. 아래 **Add a README file** 은 체크하지 말고 초록색 **Create repository** 클릭

## 2단계 — 파일 올리기

1. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭
   (또는 `Add file` → `Upload files`)
2. 탐색기에서 `android` 폴더를 열고, **폴더 안의 내용물 전부**를
   브라우저 창에 끌어다 놓습니다.

   올라가야 할 것:
   ```
   main.py
   lotto645.py
   buildozer.spec
   .gitignore
   assets/          (폴더째로)
   .github/         (폴더째로)  ← 이게 빌드 설정입니다. 꼭 포함하세요
   ```

   > `.github` 폴더가 안 보이면 탐색기에서
   > **보기 → 숨긴 항목** 을 켜 주세요.

3. 아래 **Commit changes** 버튼 클릭

## 3단계 — 빌드 기다리기

1. 저장소 상단 **Actions** 탭 클릭
2. `Build Android APK` 가 노란 점(진행 중)으로 돌고 있습니다
3. **처음 빌드는 30~45분** 걸립니다 (SDK/NDK 내려받기 때문).
   두 번째부터는 캐시가 있어 5~10분입니다.
   창을 닫아도 서버에서 계속 진행됩니다.
4. 초록색 체크 ✓ 로 바뀌면 완료

## 4단계 — APK 받아서 설치

1. 완료된 빌드를 클릭 → 페이지 맨 아래 **Artifacts**
2. **Lotto645-APK** 를 클릭하면 zip으로 받아집니다
3. zip을 풀면 `lotto645-1.0-arm64-v8a-debug.apk` 가 나옵니다
4. 이 파일을 휴대폰으로 옮깁니다 (카톡 나에게 보내기 / USB / 구글 드라이브 등)
5. 휴대폰에서 파일을 탭 → **"이 출처의 앱 설치 허용"** 을 켜 주세요
   - 안드로이드가 처음 보는 앱이라 경고가 뜹니다. 직접 만든 앱이라 정상입니다.
   - 설정 → 앱 → 특수 액세스 → 알 수 없는 앱 설치 에서도 켤 수 있습니다
6. 설치 완료. 홈 화면에 로또공 아이콘이 생깁니다.

---

## 빌드가 실패하면

Actions 탭에서 빨간 X 를 클릭하면 어느 단계에서 멈췄는지 보입니다.
**build-logs** 아티팩트도 자동으로 남습니다.
그 화면을 캡처해서 저에게 보여주시면 원인을 찾아 고쳐 드리겠습니다.

가장 흔한 경우:
- `.github` 폴더를 안 올림 → Actions 탭에 아무것도 안 뜸
- 무료 계정의 월간 빌드 시간 초과 → 다음 달 또는 저장소를 Public 으로 전환

## 다시 빌드하려면

파일을 고쳐서 다시 올리면 자동으로 빌드됩니다.
그냥 다시 돌리고 싶으면 Actions → `Build Android APK` →
**Run workflow** 버튼을 누르면 됩니다.

## 앱 사용법 (PC 버전과 동일)

| 화면 | 내용 |
|---|---|
| **번호 생성** | 게임 수 1~10, 완전분산, 자동 저장, 포함/제외 번호, 구간 가중 슬라이더. 버튼을 누를 때마다 새 조합 |
| **적중 분석** | 생성한 번호가 자동 저장되고, 실제 당첨번호와 대조해 등수·적중률·95% 신뢰구간·손익 표시 |
| **구간 통계** | 3/4/5/6개월 구간별 고빈도·저빈도, 종합 점수, 미출현 기간, 이월번호·연속번호 분포, 필터 경계 |

- 상단 **[최신 회차 업데이트]** — 동행복권에서 새 회차를 받아 통계 재계산 + 저장된 예측 자동 채점
- 앱을 켤 때도 새 회차가 있는지 자동으로 확인합니다
- 데이터는 앱 전용 저장소에 보관됩니다 (앱을 지우면 함께 사라집니다)

## 참고 — 앱 설정 바꾸기

`buildozer.spec` 파일에서:

- `title` — 홈 화면에 표시될 이름
- `version` — 버전 번호 (올려서 다시 빌드하면 업데이트 설치됨)
- `android.archs` — 아주 오래된 폰(2018년 이전)까지 지원하려면
  `arm64-v8a, armeabi-v7a` 로 바꾸세요. 빌드 시간이 2배가 됩니다.

## 확률에 대한 안내

PC 버전 `README.md` 의 4번 항목과 동일합니다.
이 앱은 당첨 **확률을 높여주지 않습니다**. 1등 확률은 어떤 번호든
1/8,145,060 로 같습니다. 이 앱이 실제로 하는 것은
① 게임 간 완전분산으로 5등+ 당첨 확률 소폭 개선(+3.5%, 측정값),
② 인기조합 회피로 당첨 시 실수령 기대값 개선,
③ 구조적으로 비정상적인 조합 배제 — 이 세 가지뿐입니다.
